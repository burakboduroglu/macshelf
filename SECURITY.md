# Security Policy

## Supported versions

Only the latest release is supported. There are no maintenance branches — a fix
ships in the next version rather than as a patch to an older one.

| Version | Status                |
| ------- | --------------------- |
| 0.2.x   | Supported             |
| 0.1.x   | Unsupported, upgrade  |

## What MacShelf touches

Worth knowing before you report, and before you install:

- The clipboard history is stored unencrypted at
  `~/Library/Application Support/MacShelf/MacShelf.store`, readable by anything
  running as your user. It is a convenience cache, not a vault.
- Copies marked `org.nspasteboard.ConcealedType`, `TransientType` or
  `AutoGeneratedType` are skipped, as are copies made while a known
  password-manager bundle ID held focus. The concealed marker is the reliable
  half of that; the bundle ID check is best effort.
- Accessibility permission is optional and used for exactly one thing:
  synthesising `Cmd+V` for *Paste into frontmost app*.
- Releases are **ad-hoc signed, not notarized**. Nothing about the binary is
  verified by Apple, and installing means trusting an unreviewed build from a
  personal tap. If that is not acceptable, build from source.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately in one of these ways:

1. **GitHub Security Advisories** — open a private draft advisory from the
   [Security tab](https://github.com/burakboduroglu/macshelf/security/advisories/new).
   This is preferred.
2. **Email** — <info@burakboduroglu.com.tr>.

A useful report includes:

- What the issue is and where it lives (file, function, or dependency).
- Steps to reproduce, or a proof of concept.
- The impact you believe it has.
- Any suggested fix, if you have one.

## What to expect

This is a personal project maintained in spare time, so treat these as
intentions rather than guarantees: an acknowledgement within a few days, an
assessment of whether it is reproducible, and a fix in the next release if it
is. You will be credited in the release notes unless you would rather not be.
